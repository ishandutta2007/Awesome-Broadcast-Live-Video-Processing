## 🏢 SaaS & Commercial Platforms 💼

> **Market Analysis & Fragmentation Overview:**  
> The global live video processing and cloud encoding market size is estimated at **$2.8 Billion USD in 2026** and is projected to surpass **$5.4 Billion USD by 2032** (growing at ~11.5% CAGR). The sector is **moderately fragmented**: cloud hyper-scalers (such as AWS Elemental) dominate cloud-native live encoding workflows, while specialized video infrastructure platforms (Bitmovin, Wowza, Harmonic, LiveU) maintain dedicated market shares for broadcast-grade low-latency packaging, hardware contribution, and live remote production.

The broadcast live video processing market spans cloud-native encoding services and on-premises playout systems. Codec adoption is shifting: H.264 remains universal for general streaming, H.265/HEVC handles 4K and live sports, AV1 delivers high-compression bandwidth savings for linear FAST channels, and VVC/H.266 is emerging for ultra-high-definition 8K workflows.

## 🔓 Open-Source GitHub Projects 🛠️

*Sorted strictly by GitHub Star Count (Descending)* 🌟

- **[SRS (Simple Realtime Server)](https://github.com/ossrs/srs)** [![Stars](https://img.shields.io/github/stars/ossrs/srs?style=social&color=white)](https://github.com/ossrs/srs/stargazers)  
  **Industrial-grade real-time video server**, MIT licensed. **26.1k stars** 🌟. High-performance, simple, and efficient video server supporting RTMP, WebRTC, HLS, HTTP-FLV, and SRT. Ideal for low-latency live streaming, WebRTC broadcasting, and high-concurrency video delivery. Written in C++. 🚀

- **[OBS Studio](https://github.com/obsproject/obs-studio)** [![Stars](https://img.shields.io/github/stars/obsproject/obs-studio?style=social&color=white)](https://github.com/obsproject/obs-studio/stargazers)  
  **Free and open-source software for live video recording and live streaming**, GPL-2.0 licensed. **60.5k stars** 🌟. Industry standard software for live encoding, multi-source compositing, audio mixing, and RTMP/SRT streaming output. Used worldwide by content creators and TV production switchers. 🎥

- **[MediaMTX](https://github.com/bluenviron/mediamtx)** [![Stars](https://img.shields.io/github/stars/bluenviron/mediamtx?style=social&color=white)](https://github.com/bluenviron/mediamtx/stargazers)  
  **Zero-dependency real-time media server & proxy**, MIT licensed. **14.8k stars** 🌟. Seamless multi-protocol proxy for SRT, WebRTC, RTSP, RTMP, HLS, and LL-HLS. Supports dynamic stream recording to fMP4/MPEG-TS, JWT authentication, and Prometheus telemetry. Single binary deployment for Linux, Windows, and macOS. 🔄

- **[Owncast](https://github.com/owncast/owncast)** [![Stars](https://img.shields.io/github/stars/owncast/owncast?style=social&color=white)](https://github.com/owncast/owncast/stargazers)  
  **Self-hosted live video streaming and chat server**, MIT licensed. **12.4k stars** 🌟. Single-user independent streaming server compatible with OBS, Streamlabs, and any RTMP broadcaster. Built-in chat engine, web management dashboard, and customizable embeddable web player. Built with Go and React. 🏠

- **[Zixi / SRT (Secure Reliable Transport)](https://github.com/Haivision/srt)** [![Stars](https://img.shields.io/github/stars/Haivision/srt?style=social&color=white)](https://github.com/Haivision/srt/stargazers)  
  **Open-source low-latency video transport protocol**, MPL-2.0 licensed. **2.8k stars** 🌟. Broadcast industry standard protocol for packet loss recovery, low-latency video contribution, and secure internet video transmission. Created by Haivision. 📡

- **[CasparCG Server](https://github.com/CasparCG/server)** [![Stars](https://img.shields.io/github/stars/CasparCG/server?style=social&color=white)](https://github.com/CasparCG/server/stargazers)  
  **Enterprise broadcast playout graphics & video engine**, GPL-3.0 licensed. **973 stars** 🌟. In continuous 24/7 broadcast television production since 2006. Supports multi-channel SDI, NDI, and live network stream output, AMCP automation control, HTML5 dynamic graphic overlays, and dynamic video compositing. 🎬

- **[SRT Live Server](https://github.com/Edward-Wu/srt-live-server)** [![Stars](https://img.shields.io/github/stars/Edward-Wu/srt-live-server?style=social&color=white)](https://github.com/Edward-Wu/srt-live-server/stargazers)  
  **Ultra-low latency SRT streaming relay server**, BSD-3-Clause licensed. **644 stars** 🌟. Designed for real-time live broadcast contribution and video relay. Efficiently routes high-bitrate SRT video streams across internet connections. ⚡

- **[ffplayout](https://github.com/ffplayout/ffplayout)** [![Stars](https://img.shields.io/github/stars/ffplayout/ffplayout?style=social&color=white)](https://github.com/ffplayout/ffplayout/stargazers)  
  **Rust and FFmpeg 24/7 linear playout server**, GPL-3.0 licensed. **456 stars** 🌟. Advanced linear playout automation engine written in Rust. Features web-based schedule editor, frame-accurate playlist generation, overlay logos, and low-resource H.264/HEVC encoding output. 🦀

- **[Sofie TV Automation](https://github.com/Sofie-Automation/Sofie-TV-automation)** [![Stars](https://img.shields.io/github/stars/Sofie-Automation/Sofie-TV-automation?style=social&color=white)](https://github.com/Sofie-Automation/Sofie-TV-automation/stargazers)  
  **Live TV newsroom automation control system**, MIT licensed. **310 stars** 🌟. Production-proven live news studio control system deployed by Norwegian public broadcaster (NRK) since 2018. Controls video switchers, audio mixers, graphics engines, and CasparCG playout servers. 📰

- **[OpenBroadcaster OBServer](https://github.com/openbroadcaster/observer)** [![Stars](https://img.shields.io/github/stars/openbroadcaster/observer?style=social&color=white)](https://github.com/openbroadcaster/observer/stargazers)  
  **Broadcast playout automation & CAP alerting**, AGPL-3.0 licensed. **185 stars** 🌟. GStreamer-powered radio/TV media automation server with integrated Common Alerting Protocol (CAP) emergency notification module for broadcast networks. 📻

- **[datarhei Core](https://github.com/datarhei/core)** [![Stars](https://img.shields.io/github/stars/datarhei/core?style=social&color=white)](https://github.com/datarhei/core/stargazers)  
  **Restful API orchestrator for FFmpeg processes**, Apache-2.0 licensed. **187 stars** 🌟. Zero-code development framework to deploy, scale, and manage dynamic FFmpeg video encoding pipelines via simple RESTful APIs. ⚙️

- **[Nebula Broadcast](https://github.com/nebulabroadcast/nebula)** [![Stars](https://img.shields.io/github/stars/nebulabroadcast/nebula?style=social&color=white)](https://github.com/nebulabroadcast/nebula/stargazers)  
  **Broadcast automation & Media Asset Management (MAM)**, GPL-3.0 licensed. **124 stars** 🌟. Open-source broadcast cataloging system in 24/7 production since 2012. EBU Core metadata model, CasparCG playout schedule control, NVENC GPU transcoding, and EBU R128 loudness normalization. 📺

- **[Open Source FAST Channel Engine (VOD2Live)](https://github.com/eyevinn/vod-to-live-engine)** [![Stars](https://img.shields.io/github/stars/eyevinn/vod-to-live-engine?style=social&color=white)](https://github.com/eyevinn/vod-to-live-engine/stargazers)  
  **VOD-to-Live linear FAST channel engine**, MIT licensed. **109 stars** 🌟. Converts on-demand VOD video assets into live linear HLS/DASH FAST channels with programmatic ad-insertion readiness. 📡

- **[CasparCG Media Scanner](https://github.com/CasparCG/media-scanner)** [![Stars](https://img.shields.io/github/stars/CasparCG/media-scanner?style=social&color=white)](https://github.com/CasparCG/media-scanner/stargazers)  
  **Media file indexing service for CasparCG**, MIT licensed. **32 stars** 🌟. Service worker for CasparCG playout clusters. Automatically generates video metadata, audio waveforms, and thumbnail previews for AMCP playout clients. 🔍

- **[Constatus](https://github.com/folkertvanheusden/constatus)** [![Stars](https://img.shields.io/github/stars/folkertvanheusden/constatus?style=social&color=white)](https://github.com/folkertvanheusden/constatus/stargazers)  
  **Multi-input live video processing & motion detection**, GPL-2.0 licensed. **28 stars** 🌟. High-performance video processing server supporting V4L2, RTSP, MJPEG, and GStreamer inputs with realtime overlay, motion filtering, and HTTP streaming outputs. 🎥

- **[CasparCG Client (t4Playout)](https://github.com/mekhti/t4Playout)** [![Stars](https://img.shields.io/github/stars/mekhti/t4Playout?style=social&color=white)](https://github.com/mekhti/t4Playout/stargazers)  
  **Python desktop playout client for CasparCG**, GPL-3.0 licensed. **2 stars** 🌟. Minimalist playout controller for broadcast operators scheduling video clips and graphic rundown lists on CasparCG Server. 🎛️
